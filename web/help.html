Park a vehicle

Enter the plate, choose the vehicle type and select a starting space. Click Park vehicle. The plate must not already be parked.

Move a vehicle

Click the parked vehicle to select its plate. Select the destination and click Move vehicle. You can also drag the vehicle onto a destination space on the map.

To move between levels, select the vehicle, change the displayed level, click the destination space and use Move vehicle.

Bus spaces

A bus needs five consecutive large spaces in the same row and level. Select the first space of the group. All five spaces must be available, except spaces already occupied by the same bus during a move.

For example, a bus starting at 1-B-3 uses 1-B-3 through 1-B-7. Level 3 has no large spaces and cannot accept a bus.

Find a vehicle

Enter the plate and click Find vehicle. The message shows its location. Matching spaces have a purple outline, and the map switches to that level.

Vehicle departure

Enter or select the plate and click Vehicle departure. All spaces occupied by that vehicle become available.

Map and records

Each space shows Available or Occupied as text. M means motorcycle space, C means compact and L means large. The map is schematic and is not drawn to scale.

The vehicle list is sorted by type and plate. Recent activity shows up to 100 successful actions, newest first.

Errors and connection

Blocked actions show an error message and keep existing parking records. If the connection fails, check that the Java server is running and click Refresh data.

Records are stored in memory and reset when the Java server restarts.
