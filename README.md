# Parking Management System

Assessment project for ICTPRG532.

## Parking layout

The car park has three levels and 60 spaces.
Each level has rows A, B and C.

| Level | Row A | Row B | Row C |
|-------|-------|-------|-------|
| 1 | 5 motorcycle spaces | 10 large spaces | 5 compact spaces |
| 2 | 5 motorcycle spaces | 10 compact spaces | 5 large spaces |
| 3 | 5 motorcycle spaces | 10 compact spaces | 5 compact spaces |

## Parking rules

- Motorcycles can use any space.
- Cars can use compact or large spaces.
- Buses need five consecutive large spaces in the same row.

## Development

The application will use C++ and Java.
